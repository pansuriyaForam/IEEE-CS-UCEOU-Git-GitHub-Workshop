## 🌎 Open Source

Once you understand Git and GitHub, start exploring open-source projects.

Don't immediately try to contribute code to a huge project.

Instead:

1. Find a project that interests you.
2. Read its README.
3. Look at its contribution guidelines.
4. Explore its Issues.
5. Look at existing Pull Requests.
6. Understand how contributors communicate.
7. Start with a small contribution.

The repository you are currently viewing follows the same basic workflow.

---

## 🔎 Finding Beginner-Friendly Contributions

When exploring GitHub repositories, look for labels such as:

```text
good first issue
help wanted
documentation
beginner
```

These labels often indicate issues that may be suitable for newer contributors.

However, always read the project's contribution guidelines before starting work.
