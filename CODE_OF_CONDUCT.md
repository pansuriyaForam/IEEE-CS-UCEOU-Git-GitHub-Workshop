# Code of Conduct 🤝

## Our Commitment

The **Git & GitHub Workshop - IEEE Computer Society UCEOU** is intended to be a welcoming and respectful learning environment for everyone.

We welcome contributions from people with different levels of experience, including those making their **first GitHub contribution**.

By participating in this repository, you agree to help maintain a constructive and inclusive environment.

---

## Expected Behavior

We encourage all contributors to:

- 💬 Communicate respectfully and constructively.
- 🤝 Be welcoming to beginners and people with different levels of experience.
- 🧠 Give and receive feedback professionally.
- 📚 Ask questions when something is unclear.
- 🔍 Focus discussions on the contribution or technical problem.
- 🌱 Help others learn when you can.
- 📝 Use Issues and Pull Requests for their intended purposes.
- ❤️ Assume good intentions while communicating.

Remember that a Pull Request is part of a learning process. Not every contribution will be perfect, and that's okay.

---

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, discrimination, or personal attacks.
- Insulting or humiliating other contributors.
- Trolling or deliberately disrupting discussions.
- Publishing someone else's private information without permission.
- Intentionally submitting malicious or harmful changes.
- Spam or meaningless contributions intended only to create activity.
- Any other behavior that makes the project unsafe or hostile for others.

---

## Code Review

Code review is a normal part of collaborative development.

When reviewing a Pull Request:

### Do

- Explain what could be improved.
- Ask questions when clarification is needed.
- Suggest specific improvements.
- Focus on the code, documentation, or contribution.

### Don't

- Attack the person who made the contribution.
- Use insulting or dismissive language.
- Assume someone already knows something simply because it seems obvious to you.

A review should help improve the contribution **and help the contributor learn**.

---

## Reporting a Problem

If you experience or observe behavior that violates this Code of Conduct, please report it to the workshop organizers or repository maintainers.

For technical problems with the project, please use the appropriate GitHub Issue.

For conduct-related concerns, please avoid discussing sensitive details publicly in an Issue or Pull Request.

---

## Scope

This Code of Conduct applies to interactions related to this repository, including:

- Issues
- Pull Requests
- Code reviews
- Discussions
- Contributions
- Other project-related communication

---

## Our Goal

The purpose of this repository is not simply to collect commits or Pull Requests.

It is a place to **learn, practice, collaborate, and contribute**.

Let's make it a space where someone can confidently make their first contribution and feel comfortable making their second.
